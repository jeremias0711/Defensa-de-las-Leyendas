# Ancestrales · El último recuerdo (Defensa de las Leyendas)

Las leyendas colombianas defienden el Libro Sagrado contra El Olvido. Tower Defense hecho con Unity 6.

**Jugar:** https://jeremias0711.github.io/Defensa-de-las-Leyendas/

Funciona en el navegador del computador y del teléfono (en horizontal), sin instalar nada.

Este repositorio contiene solo la versión web compilada (WebGL). Créditos y licencias de los recursos de terceros:
fuentes Fredoka y MedievalSharp bajo SIL Open Font License 1.1 (TemplateData/fonts/).
